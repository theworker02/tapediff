# tapediff

Tape digests and diff fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/tapediff/

## Install / run

```bash
git clone https://github.com/theworker02/tapediff.git
cd tapediff
node src/cli.js
node --test
```
